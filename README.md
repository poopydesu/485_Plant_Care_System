# Plant Care System 
> A plant care system that allows users to browse various plant information, log their own plants, and learn more about their plants.

## Contributors
Megan Warren and Rachal Thornton

## Coding Languages and Tools Used
HTML, PHP, SQL, and JavaScript

## Setup
1. Copy `.env.example` to `.env` and fill in variables for all database credentials. 
2. Run SQL scripts to populate tables and plant data
3. Use localhost to run the site

## Sources
- All plant data comes from the [Indoor Plant Health And Growth Dataset](https://www.kaggle.com/datasets/souvikrana17/indoor-plant-health-and-growth-dataset) on Kaggle
- Index page image from [Gary Barnes on Pexels](https://www.pexels.com/photo/crop-gardeners-against-assorted-potted-plants-on-table-6231871/)
