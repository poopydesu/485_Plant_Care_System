# Plant Care System 
> A plant care system that allows users to browse various plant information, log their own plants, and learn more about their plants.

## Contributors
Megan Warren and Rachal Thornton

## Coding Languages and Tools Used
HTML, PHP, SQL, and JavaScript

## Setup
1. Copy `.env.example` to `.env` and fill in variables for all database credentials. 
2. Run SQL scripts, `schema.sql` then `data.sql`, to populate tables and plant data.
3. Use VSCode Serve PHP project on localhost to run the site.
